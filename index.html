About me

I'm a final-year Computer Science student at the Technion – Israel Institute of Technology, graduating in March 2027. I like working across the stack, from system calls all the way up to the person using the app.

In a team of three, I co-developed and published DayCraft, an AI-powered study planner on Google Play. I integrated the Google Gemini API to turn students' goals into study checklists and schedules, and built the Firebase backend behind it.

My coursework projects go deeper: a multithreaded web server in C, a Linux shell in C++, a PostgreSQL analytics layer, and machine-learning and AI algorithms written from scratch in Python, all built on a solid base of data structures and algorithms.

Outside class, I mentored 8 high-school students with QueenB as they built their first web apps.

An AI-powered study planner for university students

Students set their goals, and DayCraft's Gemini-powered assistant turns them into study checklists and schedule plans, with courses, deadlines and reminders in one place.

  • Integrated the Google Gemini API, enforcing structured JSON responses with fallback parsing for unexpected output
  • Built the Firebase backend: email/password auth, a per-user, per-semester Firestore model, and batched writes for consistent updates
  • Schedule-conflict detection that flags overlapping courses before they're added
  • Deadline reminders 24 hours ahead, using timezone-aware local notifications
  • An in-app reporting tool that lets users flag inaccurate or unsafe AI responses
